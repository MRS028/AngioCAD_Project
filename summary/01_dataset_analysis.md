# Dataset Analysis Summary

The initial stage of this study focused on performing a comprehensive analysis of the AngioCAD dataset to understand its clinical characteristics, image organization, and disease distribution before image preprocessing and model development.

The dataset consists of patient-wise coronary angiography image sequences accompanied by two structured clinical spreadsheets: **Features** and **Labels**. The Features file contains demographic information, cardiovascular risk factors, laboratory measurements, and clinical findings, whereas the Labels file provides expert-annotated coronary artery stenosis information for fifteen major coronary segments along with the corresponding right and left coronary angiographic series.

The two spreadsheets were merged using the unique patient identifier (ID), resulting in a unified dataset containing complete clinical and diagnostic information for each patient. Following the merge, descriptive statistical analysis was performed to summarize patient demographics, including age, sex, body mass index (BMI), cardiovascular risk factors, laboratory parameters, and diagnosis categories.

To quantify coronary artery disease severity, stenosis values from all coronary vessels were parsed into numerical percentages. Summary statistics including the mean, median, standard deviation, minimum, maximum, and prevalence of significant stenosis (≥50%) were computed for each coronary artery. Additionally, several clinically meaningful labels were generated, including binary CAD classification (presence or absence of significant coronary artery disease), maximum stenosis, severity category, and the number of diseased vessels per patient.

The image dataset was analyzed independently from the clinical records. Images are organized hierarchically by patient identifier, where each patient folder contains multiple angiographic series, and each series consists of sequential image frames extracted from coronary angiography videos. The image analysis calculated the total number of patients, total number of angiographic series, total image frames, average number of frames per patient, minimum and maximum frame counts, and the distribution of right and left coronary artery image sequences based on the clinical annotations.

Exploratory statistical analyses were further conducted to investigate relationships between clinical variables and coronary artery disease. Pearson correlation analysis was applied to evaluate associations among age, BMI, diabetes mellitus (DM), hypertension (HTN), hyperlipidemia, smoking status, and CAD severity. Correlation matrices and heatmaps were generated to visualize these relationships. Furthermore, Chi-square tests were performed to examine the association between categorical clinical variables and CAD status.

Several visualization techniques were employed to better understand the dataset distribution, including age distribution, sex distribution, diagnosis frequency, CAD prevalence, severity class distribution, stenosis distribution across coronary arteries, image distribution per patient, diseased vessel distribution, risk factor prevalence, correlation heatmaps, and coronary image series statistics.

Overall, this dataset analysis provided a comprehensive understanding of both the clinical and imaging components of the AngioCAD dataset, identified potential class imbalance and clinical trends, verified dataset integrity, and established a solid foundation for the subsequent image preprocessing, series processing, data augmentation, and deep learning model development stages.
